## Deified コントローラー対応の概要：どの入力が機能するか

何かを接続する前に、各入力タイプが一般的にどのような体験をもたらすかを知っておくと役立ちます。以下の表は、このスタイルのPC向けタイトルで多くのプレイヤーが報告している内容を反映しています。

| 入力タイプ | 接続 | 一般的な初期状態での結果 | 最適な用途 |
|---|---|---|---|
| Xbox ワイヤレスコントローラー | Bluetooth または USB-C | 通常は即座に認識される | プラグアンドプレイを好むプレイヤー |
| Xbox 有線コントローラー | USB-A | 最も信頼性が高く、ペアリング手順が不要 | 長時間セッション、遅延ゼロ |
| DualSense（PS5） | USB-C または Bluetooth | 動作するが、ボタンプロンプトが Xbox アイコンで表示されることがある | PlayStation レイアウトを好むプレイヤー |
| DualShock 4（PS4） | USB または Bluetooth | 概ね問題ないが、時々再マッピングが必要 | 予算重視の選択肢 |
| Switch Pro コントローラー | Bluetooth | Steam Input の有効化が必要なことが多い | Nintendo スタイルの人間工学 |
| 汎用・サードパーティ製パッド | USB またはドングル | 当たり外れがあり、XInput モードが必要なことも | カジュアルな予備コントローラー |
| キーボード＋マウス | ネイティブ | 常に動作する | 精密なエイムを好むプレイヤー |

**重要なポイント：** 有線の Xbox スタイルコントローラーは依然として最も抵抗の少ない選択肢です。deified controller support で頭を悩ませる時間を最小限にしたいなら、まずそこから始めて、後で他のものに広げていきましょう。

### 有線 vs. ワイヤレス：実際に何が変わるか

有線接続は、バッテリー残量と Bluetooth ペアリングという2つの変数を一度に排除します。コミュニティの報告では、Bluetooth から直接 USB ケーブルに切り替えたプレイヤーが「コントローラーが検出されない」問題を解決する頻度が、他のどの単一の修正よりも高いことが一貫して示されています。

ワイヤレスもまったく問題なく使えます。ただし、Bluetooth の干渉、バッテリー残量の低下、競合するデバイスがすべてゲームのバグのように見える可能性があることは覚えておきましょう。

## Deified コントローラー対応を有効にする手順

以下の手順を順番に進めてください。ほとんどのプレイヤーは手順4を超える必要はありません。

| 手順 | 操作 | 重要な理由 |
|---|---|---|
| 1 | ゲームを起動する**前に**コントローラーを接続する | 多くのタイトルは起動時にのみ入力デバイスをスキャンする |
| 2 | Steam（または使用中のランチャー）を開き、設定にコントローラーが表示されることを確認する | OS がハードウェアを認識していることの証明になる |
| 3 | ゲームで Steam Input を有効にする、またはプロンプトがおかしい場合は「強制オフ」に設定する | ボタンアイコンの不一致を解決する |
| 4 | ゲームを起動してコントロールメニューを開く | ゲームがパッドを検出していることを確認する |
| 5 | オプションがあれば、入力モードをキーボードからゲームパッドに切り替える | 一部のメニューでは手動での切り替えが必要 |
| 6 | リスクの低いエリアで全ボタンをテストする | デッドゾーンや未割り当てのアクションを早期に発見できる |
| 7 | しっくりきたらカスタムプロファイルを保存する | アップデート後にレイアウトを失うのを防ぐ |

ランチャーではコントローラーが動作するのにゲーム内で動作しない場合、通常は Steam Input がゲームのネイティブ検出を上書きしていることが原因です。その1つの設定を切り替えるだけで、ほとんどの場合は解決します。

### まずランチャーを確認する

Steam、Epic、GOG Galaxy、Xbox アプリはそれぞれコントローラーの扱いが少しずつ異なります。Steam は Steam Input のおかげで最も柔軟で、ほぼどんなゲームパッドでも Xbox スタイルのレイアウトに変換できます。初めて使う場合は、[Steam Input の公式ドキュメント](https://partner.steamgames.com/doc/features/steam_controller)が変換レイヤーの仕組みを平易な言葉で説明しています。

他のランチャーの場合は、ゲームを非 Steam ショートカットとして追加すれば、Steam Input でコントローラーを管理できます。回避策のように聞こえますが、実際に回避策です。しかし、機能します。

### ケーブルを見落とさないこと

驚くほど多くの「死んだ」コントローラーは、単に充電専用の USB ケーブルを使っているだけです。充電専用ケーブルは電力を供給しますがデータは送らないため、PC がデバイスを認識することはありません。何かを再インストールする前に、データ対応と分かっているケーブルに交換しましょう。

## Deified コントローラー対応のトラブルシューティング

何かが壊れたら、症状を以下の表に照らし合わせてください。これらはプレイヤー体験のスレッドで何度も何度も出てくる修正方法です。

| 症状 | 考えられる原因 | 修正方法 |
|---|---|---|
| メニューでは動作するがゲームプレイ中は動作しない | Steam Input の競合 | Steam Input をオン/オフして再起動する |
| まったく入力がない | 充電専用ケーブルまたはバッテリー切れ | ケーブルを交換し、完全充電し、別の USB ポートを試す |
| ボタンは認識されるが割り当てが違う | レイアウトの不一致（PlayStation と Xbox のプロンプト） | ゲーム内で再マッピングするか Steam Input テンプレートを適用する |
| 戦闘中に入力が途切れる | Bluetooth の干渉またはバッテリー残量の低下 | 有線に切り替え、ドングルを近づける |
| 二重入力／ゴースト入力 | 2つの入力元が同時に有効になっている | 使っていないデバイスを切断する |
| Alt+Tab 後にコントローラーが切断される | ランチャーのフォーカス問題 | 再接続してからゲームウィンドウに戻る |
| スティックのドリフト | ハードウェアの劣化 | デッドゾーンを調整し、それでもダメなら交換を検討する |

### ほとんどの問題を解決する3つの修正

- **ゲームの実行中に再接続する。** 多くのプレイヤーは、セッションの途中で抜き差しするだけで検出問題を解決しています。
- **ゲームだけでなくランチャーも再起動する。** ランチャーのコントローラーサービスは、時々新しく起動し直す必要があります。
- **ゲームファイルを検証する。** 入力設定の破損は稀ですが実在し、検証はすぐに終わります。

3つすべてを試しても何も変わらない場合は、別のゲームでコントローラーをテストしてください。その1つのテストで、問題がハードウェアにあるのかセットアップにあるのかが分かります。

## 再マッピング：自分に本当に合うレイアウトを作る

デフォルトレイアウトは可能な限り幅広い層向けに設計されているため、個人にとって理想的であることはほとんどありません。少しの再マッピング作業がプレイスルー全体で報われます。

| アクションの種類 | 一般的なデフォルト | より良いことが多い割り当て |
|---|---|---|
| 弱攻撃 | フェイスボタン | ショルダーボタン（親指をスティックに置いたままにできる） |
| 回避／ダッシュ | フェイスボタン | バンパーまたは背面パドル |
| インタラクト | 十字キー | フェイスボタン |
| ロックオン／ターゲット | スティック押し込み | 専用のバンパー |
| アイテム使用 | 十字キー | パドルまたはトリガー修飾キー |

### より良いレイアウトのための優先事項

1. **親指をスティックから離さない。** 常に使うアクションはショルダーボタンかパドルに配置しましょう。
2. **スティック押し込みを避ける。** 精度が悪く、他のどの部品よりも早く摩耗します。
3. **関連するアクションをまとめる。** 攻撃と回避は手の位置を変えずに届くようにしましょう。
4. **メニュー用にボタンを1つ空けておく。** 思っている以上に使うことになります。

気に入ったレイアウトが見つかったら、名前付きプロファイルとして保存しましょう。アップデートで時々キー割り当てがリセットされることがあり、保存済みプロファイルなら数秒で読み込めます。

## FAQ

### Deified は PC で完全なコントローラー対応を備えていますか？

ほとんどの場合、deified controller support は有線の Xbox スタイルパッドでそのまま動作し、しかも快適に動作します。ワイヤレスパッドや PlayStation スタイルのコントローラーも概ね機能しますが、Steam Input を有効にするか、画面のプロンプトが Xbox アイコンで表示されることを受け入れる必要があるかもしれません。

### Deified でコントローラーが検出されないのはなぜですか？

最も一般的な3つの原因は、充電専用の USB ケーブル、気づかないうちに切断された Bluetooth ペアリング、ゲームのネイティブ検出と競合する Steam Input の設定です。別のタイトルでコントローラーをテストしてハードウェアの故障を除外してから、上のトラブルシューティング表を順に試してください。

### Deified でボタンを再マッピングできますか？

はい。再マッピングはゲーム内のコントロールメニューから可能で、ゲーム自体のオプションが物足りない場合は Steam Input でさらに細かく設定できます。コミュニティの報告によれば、回避と攻撃をショルダーボタンに移動することが、ほとんどのプレイヤーにとって最も効果の大きい変更だと言われています。

### Deified にはどのコントローラーが最適ですか？

Xbox Series X|S ワイヤレスコントローラーが最も安全な選択です。Windows が追加設定なしでネイティブに認識するからです。パドルや調整可能なトリガーが欲しい場合は、Elite スタイルのパッドにステップアップしましょう。予算を抑えたいなら、DualShock 4 がペアリングさえ済めば快適に動作します。

## Deified コントローラー対応に関する最終的な考え

コントローラーの問題はその瞬間は壊滅的に感じられますが、ほとんどは浅いものです。ケーブル、トグルの設定、リフレッシュが必要なペアリングなどです。最も簡単な修正から始め、トラブルシューティング表を順に下っていき、一度に5つの設定を変えるのではなく、一度に1つの変数だけをテストしましょう。

起動前にハードウェアをセットアップし、自分の手に合わせて10分間再マッピングし、そのプロファイルを保存しましょう。それさえすれば、deified controller support は技術的なハードルではなくなり、二度と気にすることのないものになります。
